This API provides an forensic AI detector designed to analyze AI text patterns. It determines the likelihood that a piece of text was generated by an AI models or a human.

:::note
For the highest accuracy, we recommend passing a minimum of **50 characters** of text. Shorter texts may yield inconclusive results.
:::

## Endpoint

```text
POST https://heavstal.com.ng/api/v1/sentinel
```

## Request Parameters

The following parameters are accepted in the request body:

| Field | Type | Required | Description |
| :--- | :--- | :--- | :--- |
| `text` | `string` | **Yes** | The content to analyze. |

## Request Examples

<Tabs>
  <TabItem label="cURL">
  ```bash
  curl -X POST https://heavstal.com.ng/api/v1/sentinel \
  -H "Content-Type: application/json" \
  -H "x-api-key: <YOUR_API_KEY>" \
  -d '{"text": "This is the text I want to scan for AI patterns."}'
  ```
  </TabItem>
  <TabItem label="JavaScript (Fetch)">
  ```javascript
  const response = await fetch('https://heavstal.com.ng/api/v1/sentinel', {
    method: 'POST',
    headers: { 
      'Content-Type': 'application/json',
      'x-api-key': '<YOUR_API_KEY>' 
    },
    body: JSON.stringify({ 
      text: "This is the text I want to scan for AI patterns." 
    })
  });

  const res = await response.json();
  console.log(`Verdict: ${res.data.verdict}`);
  ```
  </TabItem>
  <TabItem label="Heavstal SDK">
  ```javascript
  import { ai } from '@heavstal/api';

  const scan = await ai.sentinel("The quick brown fox jumps over the lazy dog.");
  console.log(`Score: ${scan.score}% | Verdict: ${scan.verdict}`);
  ```
  </TabItem>
  <TabItem label="Python">
  ```python
  import requests

  url = "https://heavstal.com.ng/api/v1/sentinel"
  headers = {
      "Content-Type": "application/json",
      "x-api-key": "<YOUR_API_KEY>"
  }
  payload = {
      "text": "This is the text I want to scan for AI patterns."
  }

  response = requests.post(url, headers=headers, json=payload)
  print(response.json()["data"])
  ```
