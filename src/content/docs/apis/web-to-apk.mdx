This endpoint compiles an Android Application Package (APK) on the fly using a provided Website URL. It dynamically wraps the webpage inside an Android WebView, automatically attaching the provided App Name and Icon.

:::caution[Performance Notice]
Compiling an APK is a resource-intensive task. Requests to this endpoint may take up to **1 minutes** to resolve. Do not terminate the request early.
:::

## Endpoint

<Endpoint method="POST" url="/api/v1/tools/web2apk" />

## Request Parameters

| Field | Type | Required | Description | Example |
| :--- | :--- | :--- | :--- | :--- |
| `website_url` | `string` | **Yes** | The destination URL of the website. | `https://heavstal.com.ng` |
| `app_name` | `string` | **Yes** | The name of the installed app. | `Heavstal` |
| `icon_url` | `string` | **Yes** | Direct URL to an image to be used as the app icon. | `https://example.com/logo.png` |
| `package_name` | `string` | No | Overrides the default android package name. | `com.heavstal.app` |
| `version_name` | `string` | No | The display version (default: `1.0.0`). | `1.0.0` |
| `version_code` | `number` | No | Internal integer version (default: `1`). | `1` |

  ```python
  url = "https://heavstal.com.ng/api/v1/tools/web2apk"
  headers = {
      "Content-Type": "application/json",
      "x-api-key": "<YOUR_API_KEY>"
  }
  payload = {
  "website_url": "https://heavstal.com.ng",
  "app_name": "Heavstal App",
  "icon_url": "https://example.com/icon.png",
  "version_name": "2.1.5",
  "version_code": 14,
  "package_name": "com.mycustom.app" 
  }

  response = requests.post(url, headers=headers, json=payload)
  print(response.json()["data"]["apk_url"])
  ```
