This API translates standard text into International Morse Code and vice versa. It handles alphanumeric characters and punctuation, using standard spacing for readability.

## Endpoint

<Endpoint method="POST" url="/api/v1/morse" />

## Request Parameters

The following parameters are accepted in the request body:

| Field | Type | Required | Description |
| :--- | :--- | :--- | :--- |
| `text` | `string` | **Yes** | The input string (Text or Morse code). |
| `mode` | `string` | Optional | `encode` (Text to Morse) or `decode` (Morse to Text). Default: `encode`. |

## Request Examples

<Tabs>
  <TabItem label="cURL">
  ```bash
  # Encoding to Morse
  curl -X POST https://heavstal.com.ng/api/v1/morse \
  -H "Content-Type: application/json" \
  -H "x-api-key: <YOUR_API_KEY>" \
  -d '{"text": "HELLO WORLD", "mode": "encode"}'
  ```
  </TabItem>
  <TabItem label="JavaScript (Fetch)">
  ```javascript
  const response = await fetch('https://heavstal.com.ng/api/v1/morse', {
    method: 'POST',
    headers: { 
      'Content-Type': 'application/json',
      'x-api-key': '<YOUR_API_KEY>' 
    },
    body: JSON.stringify({ 
      text: '... --- ...',
      mode: 'decode'
    })
  });

  const res = await response.json();
  console.log(res.data.output);
  ```
  </TabItem>
  <TabItem label="Heavstal SDK">
  ```javascript
  import { tools } from '@heavstal/api';

  // Encode
  const encoded = await tools.morse("HELLO", "encode"); 
  console.log(encoded.data.output); // Output: .... . .-.. .-.. ---

  // Decode
  const decoded = await tools.morse("... --- ...", "decode");
  console.log(decoded.data.output); // Output: SOS
  ```
  </TabItem>
  <TabItem label="Python">
  ```python
  import requests

  url = "https://heavstal.com.ng/api/v1/morse"
  headers = {
      "Content-Type": "application/json",
      "x-api-key": "<YOUR_API_KEY>"
  }
  payload = {
      "text": "HELLO WORLD",
      "mode": "encode"
  }

  response = requests.post(url, headers=headers, json=payload)
  print(response.json()["data"]["output"])
  ```
