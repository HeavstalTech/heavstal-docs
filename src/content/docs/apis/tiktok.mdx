A dual-purpose engine. You can provide a direct **TikTok URL** to download a specific video, OR provide a **Search Query** to automatically find and download the top result for that keyword.

## Endpoint

```text
POST https://heavstal.com.ng/api/v1/tiktok
```

## Request Parameters

The following parameters are accepted in the request body:

| Field   | Type     | Required | Description |
| :------ | :------- | :------- | :---------- |
| `query` | `string` | **Yes**  | A valid TikTok URL **OR** a text search term (e.g., "soccer skills"). |
| `url`   | `string` | Optional | Alias for `query` (legacy support). |

## Request Examples

Choose your preferred method to interact with the TikTok API:

<Tabs>
  <TabItem label="cURL">
  ```bash
  curl -X POST https://heavstal.com.ng/api/v1/tiktok \
  -H "Content-Type: application/json" \
  -H "x-api-key: <YOUR_API_KEY>" \
  -d '{"query": "https://vt.tiktok.com/..."}'
  ```
  </TabItem>
  <TabItem label="JavaScript">
  ```javascript
  const response = await fetch('https://heavstal.com.ng/api/v1/tiktok', {
    method: 'POST',
    headers: { 
      'Content-Type': 'application/json',
      'x-api-key': '<YOUR_API_KEY>' 
    },
    body: JSON.stringify({ 
      query: 'https://vt.tiktok.com/...' 
    })
  });

  const res = await response.json();
  console.log(res.data);
  ```
  </TabItem>
  <TabItem label="Heavstal SDK">
  ```javascript
  import { downloader } from '@heavstal/api';

  // Video Extraction
  const video = await downloader.tiktok("https://vt.tiktok.com/..."); 
  console.log(video.no_watermark);

  // Image Slides Extraction
  const slide = await downloader.tiktokSlide("https://vt.tiktok.com/...");
  console.log(slide.slideImages);
  ```
  </TabItem>    
  <TabItem label="Python">
  ```python
  import requests

  url = "https://heavstal.com.ng/api/v1/tiktok"
  headers = {
      "Content-Type": "application/json",
      "x-api-key": "<YOUR_API_KEY>"
  }
  payload = {
      "query": "https://vt.tiktok.com/..."
  }

  response = requests.post(url, headers=headers, json=payload)
  print(response.json()["data"])
  ```
  </TabItem>
</Tabs>
