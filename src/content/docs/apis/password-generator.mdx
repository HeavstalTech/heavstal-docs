This API creates secure passwords. Unlike standard random generators, this API uses high-entropy randomness suitable for production security keys and user credentials.

:::tip
After generating a password, you can store it in the **Heavstal Password Manager**
:::

## Endpoint

```text
POST https://heavstal.com.ng/api/v1/password-generator
```

## Request Parameters

The following parameters are accepted in the request body:

| Field | Type | Required | Description |
| :--- | :--- | :--- | :--- |
| `length` | `number` | Optional | Length of the password (Min: 4, Max: 128, Default: 16). |
| `uppercase` | `boolean`| Optional | Include A-Z? (Default: `true`). |
| `numbers` | `boolean`| Optional | Include 0-9? (Default: `true`). |
| `symbols` | `boolean`| Optional | Include !@#$%...? (Default: `true`). |

## Request Examples

<Tabs>
  <TabItem label="cURL">
  ```bash
  curl -X POST https://heavstal.com.ng/api/v1/password-generator \
  -H "Content-Type: application/json" \
  -H "x-api-key: <YOUR_API_KEY>" \
  -d '{"length": 24, "symbols": false}'
  ```
  </TabItem>
  <TabItem label="JavaScript (Fetch)">
  ```javascript
  const response = await fetch('https://heavstal.com.ng/api/v1/password-generator', {
    method: 'POST',
    headers: { 
      'Content-Type': 'application/json',
      'x-api-key': '<YOUR_API_KEY>' 
    },
    body: JSON.stringify({ 
      length: 24, 
      symbols: false 
    })
  });

  const res = await response.json();
  console.log(res.data.password);
  ```
  </TabItem>
  <TabItem label="Heavstal SDK">
  ```javascript
  import { tools } from '@heavstal/api';

  const pass = await tools.passwordGenerator({ 
    length: 24, 
    uppercase: true, 
    numbers: true, 
    symbols: true 
  });
  
  console.log(`Password: ${pass.data.password} | Entropy: ${pass.data.entropy_bits}`);
  ```
  </TabItem>
  <TabItem label="Python">
  ```python
  import requests

  url = "https://heavstal.com.ng/api/v1/password-generator"
  headers = {
      "Content-Type": "application/json",
      "x-api-key": "<YOUR_API_KEY>"
  }
  payload = {
      "length": 24,
      "symbols": False
  }

  response = requests.post(url, headers=headers, json=payload)
  print(response.json()["data"]["password"])
  ```
  </TabItem>
</Tabs>
