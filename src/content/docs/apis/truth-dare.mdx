This API provides random "Truth" questions or "Dare" challenges to create a fun, interactive experience for chat bots and games. 

To make the response visually appealing in modern UI wrappers, it returns the text challenge alongside a curated thematic image URL.

## Endpoint

```text
POST https://heavstal.com.ng/api/v1/truth-dare
```

## Request Parameters

The following parameters are accepted in the request body:

| Field | Type | Required | Description |
| :--- | :--- | :--- | :--- |
| `type` | `string` | **Yes** | Select mode: `truth` or `dare`. |

## Request Examples

<Tabs>
  <TabItem label="cURL">
  ```bash
  curl -X POST https://heavstal.com.ng/api/v1/truth-dare \
  -H "Content-Type: application/json" \
  -H "x-api-key: <YOUR_API_KEY>" \
  -d '{"type": "dare"}'
  ```
  </TabItem>
  <TabItem label="JavaScript (Fetch)">
  ```javascript
  const response = await fetch('https://heavstal.com.ng/api/v1/truth-dare', {
    method: 'POST',
    headers: { 
      'Content-Type': 'application/json',
      'x-api-key': '<YOUR_API_KEY>' 
    },
    body: JSON.stringify({ 
      type: 'dare' 
    })
  });

  const res = await response.json();
  console.log(res.data.result);
  ```
  </TabItem>
  <TabItem label="Heavstal SDK">
  ```javascript
  import { tools } from '@heavstal/api';

  const game = await tools.truthDare("dare");
  console.log(`Dare: ${game.data.result} | Image: ${game.data.image}`);
  ```
  </TabItem>
  <TabItem label="Python">
  ```python
  import requests

  url = "https://heavstal.com.ng/api/v1/truth-dare"
  headers = {
      "Content-Type": "application/json",
      "x-api-key": "<YOUR_API_KEY>"
  }
  payload = {
      "type": "dare"
  }

  response = requests.post(url, headers=headers, json=payload)
  print(response.json()["data"])
  ```
  </TabItem>
</Tabs>
