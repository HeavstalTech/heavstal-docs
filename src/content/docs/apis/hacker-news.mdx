This API allows you to seamlessly retrieve the top 10 trending stories currently on the front page of Hacker News. Ideal for building news aggregators or daily developer briefings.

## Endpoint

<Endpoint method="POST" url="/api/v1/hacker-news" />


## Request Parameters

This endpoint does not require any JSON body parameters.

| Field | Type | Required | Description |
| :--- | :--- | :--- | :--- |
| (None) | - | - | Send an empty JSON object `{}`. |

## Request Examples

<Tabs>
  <TabItem label="cURL">
  ```bash
  curl -X POST https://heavstal.com.ng/api/v1/hacker-news \
  -H "Content-Type: application/json" \
  -H "x-api-key: <YOUR_API_KEY>" \
  -d '{}'
  ```
  </TabItem>
  <TabItem label="JavaScript (Fetch)">
  ```javascript
  const response = await fetch('https://heavstal.com.ng/api/v1/hacker-news', {
    method: 'POST',
    headers: { 
      'Content-Type': 'application/json',
      'x-api-key': '<YOUR_API_KEY>' 
    },
    body: JSON.stringify({})
  });

  const res = await response.json();
  console.log(res.data);
  ```
  </TabItem>
  <TabItem label="Heavstal SDK">
  ```javascript
  import { search } from '@heavstal/api';

  const news = await search.hackerNews();
  console.log(news.data[0].title);
  ```
  </TabItem>
  <TabItem label="Python">
  ```python
  import requests

  url = "https://heavstal.com.ng/api/v1/hacker-news"
  headers = {
      "Content-Type": "application/json",
      "x-api-key": "<YOUR_API_KEY>"
  }

  response = requests.post(url, headers=headers, json={})
  print(response.json()["data"])
  ```
  </TabItem>
</Tabs>
