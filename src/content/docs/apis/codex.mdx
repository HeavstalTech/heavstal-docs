This API provides access to code obfuscation and encryption. It supports JavaScript (via advanced obfuscation), Python & Java (via Base64 encoding). It can be used to protect code and keys before distribution.

## Endpoint

<Endpoint method="POST" url="/api/v1/codex" />


## Request Parameters

The following parameters are accepted in the request body:

| Field | Type | Required | Description |
| :--- | :--- | :--- | :--- |
| `code` | `string` | **Yes** | The raw source code string to be obfuscated/encrypted. |
| `lang` | `string` | **Yes** | The language of the code. Options: `js`, `javascript`, `py`, `java`. |

## Request Examples

Choose your preferred method to interact with the CODE-X API:

<Tabs syncKey="code-language">

  -d '{"lang": "js", "code": "function hello() { console.log(\"Secret Code\"); }"}'

  <TabItem label="JavaScript (Fetch)" icon="seti:javascript">
  ```javascript
  const response = await fetch('https://heavstal.com.ng/api/v1/codex', {
    method: 'POST',
    headers: { 
      'Content-Type': 'application/json',
      'x-api-key': '<YOUR_API_KEY>' 
    },
    body: JSON.stringify({
      lang: "js",
      code: "function hello() { console.log('Secret Code'); }"
    })
  });

  const res = await response.json();
  console.log(res.data);
  ```
  </TabItem>
  <TabItem label="Heavstal SDK" icon="heavstal">
  ```javascript
  import { tools } from '@heavstal/api';

  const obfuscated = await tools.codex("function hello() { console.log('Secret'); }", "js");
  console.log(obfuscated.encrypted_code);
  ```
  </TabItem>
  <TabItem label="Python" icon="seti:python">
  ```python
  import requests

  url = "https://heavstal.com.ng/api/v1/codex"
  headers = {
      "Content-Type": "application/json",
      "x-api-key": "<YOUR_API_KEY>"
  }
  payload = {
      "lang": "js",
      "code": "function hello() { print('Secret Code') }"
  }

  response = requests.post(url, headers=headers, json=payload)
  print(response.json()["data"])
  ```
