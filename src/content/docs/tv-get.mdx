This API provides comprehensive metadata for a specific TV Show. It fetches the core data (including cast and a full episode list), and seamlessly merges Torrents into their episodes.

:::note
Responses are cached on the edge for **24 hours**, as historical TV series data and past episode torrents rarely change.
:::

## Endpoint

<Endpoint method="POST" url="/api/v1/tv/get" />

## Request Parameters

The following parameters are accepted in the request body:

| Field | Type | Required | Description | Example |
| :--- | :--- | :--- | :--- | :--- |
| `id` | `integer` | **Yes** | The unique TVMaze Show ID. | `169` |

  <TabItem label="Python" icon="seti:python">
  ```python
  import requests

  url = "https://heavstal.com.ng/api/v1/tv/get"
  headers = {
      "Content-Type": "application/json",
      "x-api-key": "<YOUR_API_KEY>"
  }
  payload = {
      "id": 169
  }

  response = requests.post(url, headers=headers, json=payload)
  print(response.json()["data"]["name"])
  ```

:::tip[Streaming Integration]
Want to build a streaming player? 
Do not use the `file_download` link. Instead, pass the `magnet_url` into a frontend library like **[WebTorrent.js](https://www.npmjs.com/package/webtorrent)**. It will stream the movie directly into a `<video>` tag in the browser!
:::
